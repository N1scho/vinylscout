## What SearchView Does

The SearchView component provides the complete search interface:

1. **Basic Search** - Simple query input with search button
2. **Advanced Search** - Multi-field filtering (artist, album, year, label, genre, format)
3. **Results Display** - Grid of vinyl cards with all information
4. **Price Management** - Real-time price loading and refresh
5. **Collection Integration** - Add/remove items directly from results
6. **Pagination** - Navigate through large result sets
7. **State Management** - Loading, empty, and error states
