### 1. **Camera Helpers Module**

**Location**: `src/utils/cameraHelpers.js`


**Benefits**:
- Reusable camera logic

- Easy to test independently

**Location**: `src/utils/collectionOperations.js`

**Functions**:

- `calculatePriceChange()` - Calculate price change percentage
- `getItemPriceHistory()` - Get price history for charts
- **Plus 6 more utility functions!**

**Benefits**:

- Immutable operations
- Type-safe interfaces
- Reusable across app

## 🎯 Utility Modules Reference

### Camera Helpers
```javascript
import {
  startCameraStream,
  stopCameraStream,
  captureAndAnalyzeVinyl
} from './utils/cameraHelpers';

// Start camera
const stream = await startCameraStream(
  (stream) => setStream(stream),
  (error) => setError(error)
);

// Capture and analyze
const result = await captureAndAnalyzeVinyl(
  videoRef.current,
  canvasRef.current,
  anthropicToken
);
// Returns: { artist, album }
```

### Collection Operations
```javascript
import {
  createCollectionItem,
  toggleItemFavorite,
  updateCollectionItemPrice,
  calculatePriceChange
} from './utils/collectionOperations';

// Create new item
const item = createCollectionItem(searchResult, details);

// Toggle favorite
const updated = toggleItemFavorite(collection, itemId);

// Update price
const withPrice = updateCollectionItemPrice(
  collection,
  itemId,
  29.99,
  'EUR'
);

// Calculate change
const change = calculatePriceChange(item);
// Returns: { value, isPositive, isNegative, current, previous }
```
