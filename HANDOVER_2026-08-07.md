## Issues Found & Resolution

### Root Cause: Multiple Hook Violations

Error #185 ("Maximum update depth exceeded") was caused by:

1. **Conditional hook calls** in view components
   - Files: SearchView, CameraView, CollectionView, AlbumGallery, GenreSelector
   - Pattern: `const themes = useTheme() || propThemes` (hook call in conditional context)
   - Fix: Move hook before conditional return

2. **useEffect dependency on entire store object** (App.jsx:127)
   - Pattern: `useEffect(() => {...}, [ui, view])` where effect calls ui.goBack()
   - Creates circular: effect updates → re-render → new dependency → effect runs again
   - Fix: Depend only on specific function: `[ui.goBack, view]`

3. **useCallback after conditional return** (AlbumGallery.jsx:99)
   - Hooks called after `if (!currentAlbum) return` statement
   - Violates Rules of Hooks: must be called unconditionally in same order
   - Fix: Move all hooks before conditional return

## Lessons Learned

1. **Conditional hooks are easy to miss** - They appear as legitimate code but violate React rules
   - `const x = useHook() || fallback` looks normal but breaks Rules of Hooks
   - Solution: Call hook unconditionally, use result conditionally

2. **Zustand selector optimization tricky** - useShallow and object destructuring in selectors cause infinite loops
   - Test selector changes immediately
   - Plain selectors often work better than wrapped ones

3. **Optimization work needs incremental testing** - Batching 10+ changes then debugging is expensive
   - Test after 1-3 changes max
   - Hook violations compound: each one makes the next one harder to find

4. **Git bisect is essential** - With multiple overlapping issues, bisect found root cause faster than code inspection
