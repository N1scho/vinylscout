## 💡 Key Principles to Follow

### 1. Component Composition
```javascript
// ❌ Bad: Monolithic
function SearchView() {
  return <div>{/* 500 lines of JSX */}</div>;
}

// ✅ Good: Composed
function SearchView() {
  return (
    <div>
      <SearchBar />
      <AdvancedSearch />
      <SearchResults />
      <Pagination />
    </div>
  );
}
```

### 2. Props Over Context
```javascript
// ✅ Good: Explicit props
<VinylCard vinyl={vinyl} themes={themes} onAction={handleAction} />

// ⚠️ Use context only for truly global state
const themes = useTheme(); // Theme context
const user = useUser();    // User context
```

### 3. Single Responsibility
```javascript
// ✅ Each component does one thing well
<SearchBar />        // Just search input
<VinylCard />        // Just vinyl display
<Pagination />       // Just page navigation
```

### 4. Testable by Design
```javascript
// ✅ Easy to test
function VinylCard({ vinyl, onAdd }) {
  return <div onClick={() => onAdd(vinyl)}>...</div>;
}

// Test
fireEvent.click(card);
expect(onAdd).toHaveBeenCalledWith(vinyl);
```
